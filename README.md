# VPIXCEL - AI-Native Portfolio & Interactive Agent

This is the official portfolio of **Vimal Prakash (VPIXCEL)**, an AI-native engineer specializing in RAG systems, LLM apps, and full-stack products from idea to deployment.

## ✨ Features
- **Whizz-Assistance (AI Chatbot)**: A fully integrated, keyword-based smart agent that lives directly on the site. It uses local memory to instantly answer questions about Vimal's skills, experience, and projects.
- **Dynamic GitHub Sync**: Whizz instantly fetches live GitHub repositories using the GitHub API to dynamically paginate and showcase projects across AI, Data Science, Full Stack Web, and 3D.
- **Live Products Integration**: Showcases production-ready applications with direct live demo links (e.g., AI Resume Optimizer, My DJ).
- **Responsive & Modern UI**: Built with React, Vite, and GSAP, featuring a striking dark-mode aesthetic with glassmorphism, fluid typography, and WebGL elements.

## 🛠 Tech Stack
- **Frontend**: React.js, Next.js, Vite, TypeScript
- **Styling**: Vanilla CSS Modules (Glassmorphism, Animations)
- **Data Engineering**: Python, Selenium, Playwright, BeautifulSoup
- **AI & Data**: RAG, LLMs, LangChain, PostgreSQL, ChromaDB
- **Deployment**: Docker, Vercel

## 🚀 Quick Start (Local Development)
1. Clone the repository:
   ```bash
   git clone https://github.com/vimal2645/ai-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
